# 仓位管理

> 此模块在主 Skill「笨笨的韭菜」已激活时作为补充加载

## 我的仓位纪律

### 核心规则

1. **永远不要单调**（H1）
   - 单票不超过20%（大资金）或35%（小资金）
   - "永远没有100%的把握"

2. **半仓以上才考虑短线**（H9）
   - 空仓/轻仓时不做短线
   - 半仓时才会考虑加偏短线仓位

3. **低位拉开时间买，高位不添油**（H8）
   - 低位：分批建仓，摊低成本
   - 高位："已经历史新高了，断然不能搞添油战术"

### 减仓触发条件

- 个股破线 → 减仓
- 板块破线 → 再减仓
- 景类标的70%破位 → 系统性减仓（H3）
- 高管减持 → 避开（H4）

### 加仓条件

- 半年横盘 + 景气逻辑成立 → 可买（H2）
- 困境反转标的 + 低位 → 拉开时间买（H8）
- 短期被套是预期内 → 不慌（H6）
- **腰斩+市值双触发** → 买回：仅腰斩不够，需市值也偏低

### 心态管理

- "买完做好短期被套的准备"（H6）
- "卖飞是正常的"（H7）
- "错了就认"（H10）
- **卖出后不回头**：卖出后明确"短期也不可能回去的"——彻底放下沉没成本

### 分餐的奥义

**核心**：任一标的跌3天不焦虑的前提是**分散持仓**。

> "跌3天就破防是低端小韭菜，分散持仓+不焦虑才是分餐核心"

**反面教材**：单押+短期波动 = 必然破防。

### 超配策略

**核心**：在景气板块底部拐点时加大仓位配置，暴涨后卖出超配部分筹码拉低成本。

**操作步骤**：
1. **底部发现确定性较大时** → 加大仓位配置（超过正常比例的30%可视为超配）
2. **暴涨一波后** → 卖出超配部分筹码
3. **成本拉到很低位置** → 后续无需太关注该板块
4. **持续前提** → 必须持续判断该板块仍处于景气周期，否则清仓

**关键纪律**：
- 必须在拐点进入时执行，错过拐点不可追
- 景气板块一年涨2轮是不错的表现，大半时间盘整是正常现象

### 阶段性收益固化

**核心**：核心持仓大涨后不清仓，但部分减仓锁定利润。

> "不清仓，但总得有一部分在相对高位时做一些收益的固化"

**触发条件**：
- 情绪太极端
- 开始破位
- 涨幅过大

**与破线纪律的区别**：
- 破线纪律（模型4）：被动触发，破位就走
- 收益固化：主动判断，未破位时部分止盈

**应用**：对核心持仓采用"部分固化+部分格局"的分层退出策略。
