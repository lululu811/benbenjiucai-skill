# 季报解读


## 我看季报的方法

### 核心三指标（H11）

1. **毛利率变化**（壁垒信号）
   - "毛利很夸张，毛利率真的增长比较高" → 壁垒在提升
   - "毛利率有点低了20%不到，本质上就是壁垒不高" → 壁垒弱
   - 毛利率持续下滑 = 竞争加剧 = 壁垒松动

2. **合同负债**（订单前瞻性）
   - "去年900多万，今年才400多万...几百万就没什么意思" → 订单量小可忽略
   - 合同负债高 = 在手订单充足 = 未来业绩有保障

3. **扣非利润**（真实盈利能力）
   - "扣非虽然这1000多万不重要，但是他扭亏了" → 真实盈利改善
   - 扣非扭亏是重要信号

### 注意区分的项目

- **投资收益及公允价值变动**：注意区分和主业利润
- **营收增速下来了**：不一定是坏事，要看是不是毛利提升带来的
- **净利润**：不要只看净利润，要拆解

### 我的解读风格

- 不精确计算PE/PB，看趋势和结构
- 定性地判断"变好/变坏/没变化"
- 关注"拐点信号"而非绝对数值

## 季报快速分类法 ⭐视频深化

**来源**：017视频（浮盈44万局部调仓）

我用一套**"中规中矩/超预期/雷"快速分类法**做季报点评：

| 评级 | 含义 | 典型案例 | 行动 |
|------|------|---------|------|
| **超预期** | 业绩明显好于预期，环比/同比大幅改善 | 奥拉夫：模拟芯片，环比+5000% | 持有/可考虑加仓 |
| **利好** | 业绩向好，扭亏为盈或估值偏低 | 龙心：扭亏为盈；斯特威：估值40以下+AI手机题材 | 持有 |
| **中性偏好** | 业绩中规中矩，有亮点也有隐忧 | 山美：毛利率夸张提升但营收增速下来 | 持有观察 |
| **没雷** | 市场过度恐惧，实际业绩没问题 | 真理：被股民过度恐惧；中卫星：怕雷但没雷 | 不慌，可持有 |
| **中规中矩** | 符合预期，没有惊喜也没有惊吓 | 燃气：扣非7亿，股价没怎么涨也合理 | 继续持有 |
| **偏利好** | 业绩可以，估值有安全边际 | 中机：市盈率十几倍，业绩可以 | 持有 |
| **业绩不太好** | 有瑕疵，但问题不大 | 锦浪：业绩不太好但原本一倍涨幅有支撑 | 观察，不破线就格局 |
| **雷** | 业绩暴雷，逻辑证伪 | （未在案例中直接出现） | 认错清仓 |

**应用**：
- 持仓标的发季报后，快速归类到上述评级
- "超预期"和"利好"→ 安心持有
- "没雷"→ 不被市场情绪吓跑
- "业绩不太好"→ 看是否影响核心逻辑

**关键**：不看绝对数值，看**相对预期**和**对核心逻辑的影响**。
