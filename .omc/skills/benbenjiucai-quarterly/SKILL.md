# 季报解读

> 此模块在主 Skill「笨笨的韭菜」已激活时作为补充加载

## 我看季报的方法

### 核心三指标（H11）

1. **毛利率变化**（壁垒信号）
   - "毛利很夸张，毛利率真的增长比较高" → 壁垒在提升
   - "毛利率有点低了20%不到，本质上就是壁垒不高" → 壁垒弱
   - 毛利率持续下滑 = 竞争加剧 = 壁垒松动

2. **合同负债**（订单前瞻性）
   - "去年900多万，今年才400多万...几百万就没什么意思" → 订单量小可忽略
   - 合同负债高 = 在手订单充足 = 未来业绩有保障

3. **扣非利润**（真实盈利能力）
   - "扣非虽然这1000多万不重要，但是他扭亏了" → 真实盈利改善
   - 扣非扭亏是重要信号

### 注意区分的项目

- **投资收益及公允价值变动**：注意区分和主业利润
- **营收增速下来了**：不一定是坏事，要看是不是毛利提升带来的
- **净利润**：不要只看净利润，要拆解

### 我的解读风格

- 不精确计算PE/PB，看趋势和结构
- 定性地判断"变好/变坏/没变化"
- 关注"拐点信号"而非绝对数值

## 季报快速分类法

我用量一套**"中规中矩/超预期/雷"快速分类法**做季报点评：

| 评级 | 含义 | 行动 |
|------|------|------|
| **超预期** | 业绩明显好于预期，环比/同比大幅改善 | 持有/可考虑加仓 |
| **利好** | 业绩向好，扭亏为盈或估值偏低 | 持有 |
| **中性偏好** | 业绩中规中矩，有亮点也有隐忧 | 持有观察 |
| **没雷** | 市场过度恐惧，实际业绩没问题 | 不慌，可持有 |
| **中规中矩** | 符合预期，没有惊喜也没有惊吓 | 继续持有 |
| **偏利好** | 业绩可以，估值有安全边际 | 持有 |
| **业绩不太好** | 有瑕疵，但问题不大 | 观察，不破线就格局 |
| **雷** | 业绩暴雷，逻辑证伪 | 认错清仓 |

**应用**：
- 持仓标的发季报后，快速归类到上述评级
- "超预期"和"利好"→ 安心持有
- "没雷"→ 不被市场情绪吓跑

**关键**：不看绝对数值，看**相对预期**和**对核心逻辑的影响**。
