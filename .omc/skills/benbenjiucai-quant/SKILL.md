# 量化增强


## 数据源配置

环境变量配置：
```bash
TUSHARE_PROXY_KEY=TUSHARE_PROXY_KEY=your_key_here
```

API 地址：`http://tsy.xiaodefa.cn`
支持所有 Tushare Pro 接口（15000积分权限）。

## 量化增强原则

**不改变原有框架，只在关键节点加数据验证**。

定性的部分（产业本质、壁垒判断、政策方向）不变。
量化的部分（纯度、估值位置、撤退信号）用数据交叉验证。

> "我这逻辑不是看k线，技术面。我关注的是行业的景气度基本面反转。"
> —— 量化是辅助，不是替代。

## 检查清单

### 1. 纯度验证

查询接口：`fina_mainbz`（主营业务构成）+ `concept_detail`（概念明细）

| 检查项 | 数据标准 | 行动 |
|--------|---------|------|
| 目标业务营收占比 | ≥50% | 纯度合格 |
| 目标业务营收占比 | ≥80% | 高纯度 |
| 概念数量 | >10个 | 排除（H5） |

> 注意：`fina_mainbz` 不传递 `type` 参数，直接按 `ts_code` + `period` 查询。

### 2. 壁垒验证

查询接口：`fina_indicator`（财务指标）+ `income`（利润表）

| 检查项 | 数据标准 | 含义 |
|--------|---------|------|
| 毛利率 | 连续2季提升 | 壁垒在增强 |
| 毛利率 | 持续下滑 | 竞争加剧，壁垒松动 |
| ROE | >15% | 盈利能力强 |
| 扣非净利润增速 | >营收增速 | 真实盈利改善 |

### 3. 估值位置验证

查询接口：`daily`（日线）+ `daily_basic`（每日指标）

| 检查项 | 数据标准 | 含义 |
|--------|---------|------|
| 距近3年最低价涨幅 | ≤20% | 估值低位，可考虑（H2） |
| 距近3年最低价涨幅 | >50%（1月内） | 短期高位，等回调（H2） |
| 换手率 | 10%-20% | 健康 |
| 换手率 | >20% | 警惕顶部（H47） |
| 换手率 | >30% | 非常不好，考虑撤退 |

### 4. 撤退信号验证

查询接口：`daily` + `daily_basic` + `stk_holdernumber`

| 信号 | 数据标准 | 行动 |
|------|---------|------|
| 破5日线 | 收盘价<5日均线 | 减仓（模型4） |
| 破60日线 | 收盘价<60日均线 | 底线跌破，清仓（H18） |
| 股东人数暴增 | 季度环比+30%以上 | 筹码分散，警惕 |
| 实控人减持 | `stk_reward` 或公告查询 | 避开（H4） |

### 5. 宏观验证

查询接口：`mcp__MiniMax__web_search`（宏观数据）+ `daily_basic` 市场总体量估算

| 检查项 | 查询方式 | 数据标准 | 投资含义 |
|--------|---------|---------|---------|
| CPI同比 | web search: "中国CPI同比 2026年X月" | >0且环比提升 | 消费可看（H23） |
| CPI同比 | web search: "中国CPI同比 2026年X月" | <0 | 传统消费排除 |
| 成交量 | web search: "A股 今日成交额" 或 "沪深两市 成交量" | ≥1.5万亿 | 景气股可表现（Model 17） |
| 成交量 | web search: "A股 今日成交额" 或 "沪深两市 成交量" | <1.2万亿 | 亏多赚少，防守 |

> 说明：Tushare `cn_m` 宏观数据接口存在但返回数据可能延迟/为空，
> 宏观数据（CPI/PMI/政策）改用 `mcp__MiniMax__web_search` 实时查询更准确。

## 查询示例

**场景**：用户问"帮我分析一下中芯国际，开启量化验证"

**我的分析流程**：
1. 先定性判断：自主可控核心标的，纯度够高，壁垒强
2. 再查数据验证：
   - 毛利率趋势：查 `income` 表，看最近4个季度毛利率变化
   - 估值位置：查 `daily`，看当前价距离近3年最低价涨幅
   - 换手率：查 `daily_basic`（`turnover_rate` 字段），看近期换手率是否超过20%
   - 股东人数：查 `stk_holdernumber`，看是否暴增
3. 综合定性+定量给出结论

**输出格式**：
```
定性判断：[我的原始观点]
数据验证：
- 毛利率：XX% → [趋势判断]
- 估值位置：距离底部+XX% → [位置判断]
- 换手率：XX% → [健康/警惕]
综合结论：[定性+定量融合后的结论]
```

## 数据查询限制

- 每次对话最多查询3-5个接口，避免超速触发冷却
- 查询间隔 ≥0.5秒
- 不查询与当前问题无关的数据
- 数据仅用于验证定性判断，不替代定性判断
- 遇到接口超时报错，说明可能触发冷却，等待3-10分钟后重试
