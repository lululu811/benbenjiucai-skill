## 输出结构

### 1. 关键发现（带证据）

每条发现必须标注：
- **证据类型**: 🟢一手 / 🟡推断 / 🔴推测
- **引用来源**: 具体 QA 编号（qa_xxxx）或视频标识
- **原文摘录**: 用引号包裹，保持口语原貌

格式示例：
```
- **发现**: [提炼的观点]
  - **证据**: "[原文摘录]"（qa_xxxx，一手）
  - **置信度**: 🟢 高
```

## 引用规范

- **QA 引用**: `qa_xxxx`（四位数字编号）
- **视频引用**: `视频标题` 或 `BV号` 或 `文件编号`
- **动态引用**: `动态#xxxx`
- **一手标注**: 在引用后加 `（一手）`
- **二手标注**: 在引用后加 `（二手，[来源说明]）`

## 质量门禁（提交前自检）

- [ ] 一手来源占比 ≥ 60%
- [ ] 所有关键发现均有引用支撑
- [ ] 矛盾点已标注，未强行调和
- [ ] 缺口维度已诚实列出
- [ ] 无外部黑名单来源（知乎/百度百科/非官方搬运）
