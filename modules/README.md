# 笨笨的韭菜 · 渐进加载模块系统

## 架构概览

```
SKILL.md (主文件)
    ├── 风险提示与免责声明（始终显示）
    ├── 角色扮演规则（始终加载）
    └── 模块加载器（根据关键词渐进加载）

modules/
    ├── core/                    # 核心层（始终加载）
    │   ├── identity.md          # 身份卡 + 时间线 + 智识谱系
    │   ├── thinking-models.md   # 8个心智模型
    │   └── heuristics.md        # 15条决策启发式
    │
    └── on-demand/               # 按需层（渐进加载）
        ├── market-context.md    # 市场环境判断
        ├── stock-analysis.md    # 个股分析流程
        ├── portfolio.md         # 仓位管理
        ├── quarterly-report.md  # 季报解读
        ├── industry-chain.md    # 产业链分析
        └── psychology.md        # 心态与情绪
```

## 渐进加载机制

### 核心层（始终加载）

对话开始时，系统自动加载 `modules/core/` 下的三个文件：
- `identity.md` — 我是谁、我的经历、时间线
- `thinking-models.md` — 8个心智模型（三层漏斗、三角验证等）
- `heuristics.md` — 15条决策启发式（永远不要单调、破线纪律等）

### 按需层（关键词触发）

当用户提问匹配特定关键词时，动态加载对应模块：

| 模块文件 | 触发关键词 | 内容 |
|---------|-----------|------|
| `market-context.md` | 大盘、市场、情绪、成交量、高点、低点 | 市场环境判断、情绪指标、系统性风险 |
| `stock-analysis.md` | 怎么看、能买吗、分析一下、F10、纯度 | 个股分析三层漏斗、事件三要素 |
| `portfolio.md` | 仓位、减仓、加仓、重仓、半仓、单调 | 仓位纪律、加减规则、心态管理 |
| `quarterly-report.md` | 季报、财报、业绩、毛利率、合同负债 | 季报三指标解读法 |
| `industry-chain.md` | 产业链、上下游、谁最受益、环节 | 产业链分析框架、定价权判断 |
| `psychology.md` | 被套、拿不住、慌了、怕输、心态 | 心态框架、成功四要素、劝退 |

### 加载规则

1. **首次触发加载**：模块只在首次匹配时加载，后续同话题对话不再重复加载
2. **多模块叠加**：一个提问可能触发多个模块（如"现在能买中芯吗"→ market-context + stock-analysis）
3. **上下文继承**：已加载模块的内容在对话中保持可用
4. **websearch 协同**：加载模块后，系统可调用 websearch 获取实时数据补充分析

## 使用示例

```
用户: "帮我看看中芯国际怎么样"

系统动作:
1. 核心层已加载（identity + thinking-models + heuristics）
2. 检测到"看"+"中芯国际" → 加载 stock-analysis.md
3. 可选: websearch "中芯国际 2026 财报 毛利率"
4. 按笨总框架输出分析

---

用户: "现在仓位有点重，要减吗"

系统动作:
1. 核心层已加载
2. 检测到"仓位"+"减" → 加载 portfolio.md
3. 按纪律回答（不需要 websearch）

---

用户: "被套了，慌得一匹"

系统动作:
1. 核心层已加载
2. 检测到"被套"+"慌" → 加载 psychology.md
3. 心态安抚 + 诊断病因
```

## 模块编写规范

1. **头部模板**：
   ```markdown
   # 模块：xxx
   
   > 触发条件：用户问xxx/说xxx
   > 加载方式：渐进加载
   ```

2. **内容来源**：从 SKILL.md 主文件提取，保持与主文件一致

3. **独立性**：每个模块应能独立理解，不依赖其他模块的特定内容

4. **引用规范**：引用 QA 编号或视频来源时，与主文件保持一致

5. **尾部标记**：
   ```markdown
   ---
   *本模块由核心系统渐进加载*
   ```

## 扩展方式

新增模块时：
1. 在 `modules/on-demand/` 下创建 `.md` 文件
2. 在本 README 的"按需层"表格中添加一行
3. 更新 CHANGELOG.md
