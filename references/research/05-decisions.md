## 二、决策逻辑分析

### 2.1 买入标准

笨笨的韭菜总结自己的买入逻辑为三种景气框架（#229371）：

1. **困境反转**：企业业绩处于最差阶段，往后只会更好。典型：速腾聚创（"当前业绩是最差的时候，往后只会更好" #179207）
2. **提前预判行业景气周期**：提前配置个股等待逻辑兑现。典型：存储板块、智能驾驶
3. **突发现象级事件扭转行业景气度**：马上选完标的跑步入场。典型：政策刺激、技术突破

**具体买入条件（#217933）：**
- 确定是景气股的前提下：
  - 半年内股价横盘 → 可以马上买入
  - 1个月内涨了50%以上 → 短期高位不能追，等阶段性回调再布局
- 股价不要涨很多时买入（#178239）
- 小仓位试探（#202699：阳光电源"现在的话小仓位试探吧"）
- 低位拉开时间买（#178239："可以，拉开时间去买，问题不大"）

**不买标准：**
- 短期涨幅太大、已历史新高 → 不追高（#123277）
- 高管减持 → 避开（#119594："高管刚刚发公告减持，如果没有减持，50亿的话，我会考虑打打野"）
- 纯情绪炒作、无业绩支撑 → 不参与
- 自己没有深度研究 → 不碰（#148801："你要么对ai产业链有非常深度的研究然后拥有底仓，不然你随大流搞，这次赚了下次呢"）

### 2.2 卖出标准

**核心原则：破线减仓/清仓**

- **个股破线**："破线了减仓"（通用原则，多次提及）
- **板块破线**："板块没炸之前，都可以格局，比如阳光电源暴跌了，板块也破线了，再结合特变也破5日线，再减仓"（#155655）
- **景类标的70%破位**："我的景类标的70%左右破位的时候，那么一波行情可能要结束了"（#117861）
- **黑天鹅事件**：遇到黑天鹅无法预测，先减仓保命（#158434：澜起因股权激励黑天鹅清仓）
- **逻辑兑现/改变**：逻辑不在了就要卖出
- **短期暴涨后**：涨多了就有见顶风险（#192266：臻镭主升浪中"随时都有可能卖"）

**卖出纪律：**
- 不预测明天股价，看趋势是否破位（#115007）
- 超过自己预期后，等破位就该减仓，"这样永远是正确行为"
- 卖飞是正常的，"做好卖飞的心理准备"（#192266）

### 2.3 持有逻辑

**长期持有原则：**
- **非卖品**：中芯国际被明确称为"非卖品"（#119446, #130790）
- **只输时间不输钱**："只输时间的，我前五持仓都是"（#173345）
- **逻辑没变就一直等待**："逻辑没变就一直等待即可"（通用原则）
- **不做T**："我不做T都是买了就拿着，等未来逻辑变了或者兑现了就卖出"（#118967）

**持有心态：**
- 买完做好短期被套的准备，不是股市提款机（#213987）
- 不要和股票讲感情（#213987）
- 涨得慢不要换涨得快的，说明当初买入可能是情绪脑热（#118676）

### 2.4 仓位管理原则

**仓位分配标准：**

| 资金规模 | 标的数量 | 个股比例上限 | 板块比例上限 |
|----------|----------|--------------|--------------|
| 小资金 | 5-10个 | ≤35% | — |
| 20万-100万 | 5-10个 | ≤30% | 同板块≤40% |
| 100万+ | 10个左右 | ≤20% | — |
| 200万+ | 15-20个 | 单标的几万块没意义 | — |

**关键原则：**
- **永远不要单调**："永远不要单调，我没有100%的把握"（#175326）
- **按看好程度配置仓位**："我持有的就是我看好的方向，按照仓位比例体现看好的程度"（#206008）
- **小仓位代表把握度低**："仓位小仓位大肯定是代表自己的把握度和看好程度"（#183702）
- **高位不添油战术**："高位不要添油战术，你这样会快速把成本拉升"（#115007）
- **控制成本**：成本负了就格局，成本高的等反弹（#133001：臻镭40元成本低仓位4.6%，安全）
- **半仓策略**：半仓时才会考虑加偏短线仓位（#180525）
- **无差别减仓**：系统性风险时统一减仓避险（#133001："两周前无差别减仓"）

**止损/风控：**
- 单票不建议超过20%，极限不能到25%（#115657）
- 破线减仓是核心风控手段
- 个股太分散（40个标的）无意义，收缩到10个左右（#204151, #213987）

## 三、具体案例分析（重点）

### 案例1：速腾聚创——困境反转+长期重仓

**背景**：激光雷达龙头，港股上市，智能驾驶核心标的。

**决策过程**：
- **买入时机**：在股价低位（31元附近）建仓，后持续加仓（#178620, #179207）
- **选择理由**：
  1. "速腾则是当前业绩是最差的时候，往后只会更好，有点困境反转的味道"（#179207）
  2. "还是觉得速腾市值小，弹性更大一些"（对比地平线 #174876）
  3. 相比禾赛：禾赛只能离岸账户买，资金有限没法上仓位；禾赛增速可能下降，速腾"当前业绩最差、往后只会更好"（#179207）
- **持仓状态**：第一大重仓，长期持有
- **卖出标准**：无明确卖出计划，属于核心持仓

**QA来源**：#115234, #174876, #178620, #179207, #155758, #274232

### 案例2：臻镭科技——黑天鹅应对+低仓位风控

**背景**：军工/商业航天标的，2025年9月突发董事长被留置事件。

**决策过程**：
- **持仓状态**：成本40元，仓位比例4.6%（#133001）
- **黑天鹅应对**：
  1. 将黑天鹅分类：短期情绪利空、真黑天鹅、超级黑天鹅
  2. "我由于两周前无差别减仓，所以臻雷成本也处于较低的位置（40）加上仓位比例较低（4.6%）算是比较安全的"
  3. "基于当前情况明天我个人不会卖，其他行为还得走一步看一步"
- **后续（2026年4月ST事件）**：认为146元第一大仓位难崩，但拉长1-2个月修复概率大，预估第一波下跌-20%到-36%（#266533）

**决策逻辑体现**：低仓位+低成本是应对黑天鹅的安全垫，不急于恐慌卖出。

**QA来源**：#133001, #266533, #172273, #175416

### 案例3：澜起科技——黑天鹅清仓

## 四、错误与教训

### 4.1 自身错误

**卖飞优质标的**：
- **中芯国际**：曾卖出，后买回，"非卖品"定位是在卖飞后重新确认的（#130790："珍惜筹码吧，我说过非卖品，这次无差别减，都卖飞了"）
- **海光信息**："前年海光就持有过很久，属于卖飞了"（#194790）
- **存储板块**："我之前持有大半年过，最后卖飞了，不太有资格去点评他"（#202611，指雅克/存储）

**看错标的**：
- **雅克科技**：持有大半年后认为"买入看错了就清掉了"（#129040）
- **北斗**：清仓后调整不少（#194790）

### 4.2 常见投资者错误（他对粉丝的批评）

1. **追高被套**："追十次9次是被套的"（#131695）
2. **持仓太分散**："你这资金持仓太分散了，这个毫无必要，搞个10个标的差不多了"（#213987）
3. **和股票讲感情**："不要和股票讲感情，越看越喜欢和被套了就不买了两者都是"（#213987）
4. **把股市当提款机**：期望1-2年翻倍，没有风险意识（#284224）
5. **高位加仓/添油战术**："已经历史新高了，断然不能搞添油战术"（#123277）
6. **跟风独立思考**："太多人喜欢在我的持仓里搞独立思考，然后就是各种做错"（#185685）
7. **冲动买入后焦虑**："买完就得做好短期被套的准备，你以为股市提款机呢"（通用原则）
8. **龙头战法亏损**："你这持仓和成本一看就是龙头战法，什么时候亏的受不了了戒了再说吧"（#193926）

## 五、决策框架总结

### 5.1 核心模型：景气投资三段论

```
选股 → 配置 → 持有/卖出
  ↓      ↓        ↓
景气逻辑 仓位比例 破线纪律
```

**三种景气逻辑（#229371）：**
1. 困境反转（业绩最差→向好）
2. 提前预判行业景气周期（提前布局等兑现）
3. 突发现象级事件扭转景气度（马上跑步入场）

### 5.2 买入决策树

```
是否是景气股？
  ├─ 否 → 不买
  └─ 是 → 看股价位置
       ├─ 半年横盘 → 可买
       ├─ 1月涨50%+ → 等回调
       ├─ 历史新高+高管减持 → 不买
       └─ 低位+逻辑确认 → 拉开时间买
```

### 5.3 仓位配置模型

```
看好程度 → 仓位比例
核心标的(非卖品) → 15-20%
高确定性标的 → 10-15%
弹性/困境反转 → 5-10%
打野/观察 → 1-5%
```

**硬性纪律：**
- 单票≤20%（大资金），≤35%（小资金）
- 同板块≤40%
- 总标的5-10个（20万-100万），10-15个（100万+）
- 半仓以上才考虑短线情绪仓位

### 5.4 卖出纪律

```
触发条件（任一）：
1. 个股/板块破线 → 减仓
2. 景类标的70%破位 → 行情可能结束
3. 黑天鹅事件 → 视情况减仓/清仓
4. 逻辑改变/兑现 → 卖出
5. 短期暴涨超预期 → 等破位减仓
```

### 5.5 风控原则

1. **低仓位是安全边际**：对小概率黑天鹅的应对
2. **低成本是心态安全**：通过拉开时间建仓、下跌补仓降低成本
3. **分散是生存底线**：永远不单调
4. **破线是退出信号**：不预测，只看趋势
5. **不和市场讲道理**：错了就认，及时止损

## 七、缺口与待验证

1. **具体交易成本数据**：笨笨的韭菜从未透露自己的总资金规模、单笔交易金额（除"60万""10多万"等零星提及外），无法计算精确的仓位比例变化。

2. **完整交易时间线**：充电动态中提到"我每一笔交易都第一时间发出来"（#155758），但QA语料中只有部分交易被回述，缺少按时间顺序排列的完整交易流水。

3. **盈利/亏损具体数字**：除"29天赚200%""8倍海能达"等少数案例外，大部分持仓未披露具体收益率。

4. **2025年8月之前的持仓**：QA数据始于2025年8月，此前的持仓构建过程（如海能达的完整交易）无QA记录。

5. **视频内容交叉验证**：笨笨多次提及"看选股逻辑视频""看智能驾驶那期视频"，但视频内容未纳入本次QA语料分析，部分决策逻辑可能需要视频内容补充验证。

6. **充电动态数据**：笨笨建议粉丝"每周五到周六翻一下充电动态"查看持仓（#118676），但充电动态未纳入本次QA语料。
